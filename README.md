🌤️ Weather Forecast App
A beautiful and modern weather application that provides real-time weather information for any location worldwide. Built with HTML, CSS, and JavaScript, featuring stunning glassmorphism design and smooth animations.

🎨 Design & UI

Glassmorphism Design: Modern frosted glass effect with backdrop blur
Animated Gradient Background: Dynamic color-shifting background
Responsive Layout: Perfect on all devices - desktop, tablet, and mobile
Smooth Animations: Floating icons, hover effects, and transitions
Font Awesome Icons: Beautiful weather-related icons


🌍 Weather Information

Real-time Weather Data: Current temperature and conditions
Detailed Information:

Temperature (°C)
"Feels Like" temperature
Humidity percentage
Wind speed
Visibility
Atmospheric pressure
UV Index
Sunrise & Sunset times


Weather Conditions: Clear visual representation of weather status



🚀 Demo

Enter any city name in the search box
Click the search button or press Enter
View comprehensive weather details on the results page
Navigate back to search for another location

Frontend

HTML5: Semantic markup and structure
CSS3:

Glassmorphism effects
CSS Grid & Flexbox
Animations and transitions
Responsive design with media queries


JavaScript (Vanilla):

DOM manipulation
Fetch API for weather data
URL parameter handling
Event listeners



API

WeatherAPI.com: Real-time weather data

Current weather conditions
Forecast data
Astronomical data (sunrise/sunset)



Libraries

Font Awesome 6.0.0: Icon library for weather icons
